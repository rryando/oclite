Spawn an interactive top-level session in a DIFFERENT project's directory.

Use this when work belongs in another project on disk (a different repository
or directory) rather than the current one. The spawned session is a normal,
top-level interactive session bound to the target directory - it is NOT a child
subagent of the current session. It is linked back to the calling session, so
when the spawned session finishes its first turn its result is injected back
here automatically. You will be notified; do not poll for progress.

This call returns immediately after the spawned session is created and its
first turn is kicked off. It does not block waiting for the spawned session to
complete. Continue with non-overlapping work, or stop if there is nothing else
useful to do.
